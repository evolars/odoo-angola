# Odoo E-Learning Angola (`angola.evolars.com.br`)

Instância Odoo 17.0 focada na disponibilização de cursos de programação em Angola via E-learning (`website_slides`), materiais em PDF, integração de e-mail idêntica à Evolars (Resend Hub) e infraestrutura no Railway.

## Módulos Principais
- `website`: Base web e portal
- `website_slides`: Plataforma de E-learning e Cursos
- `evolars_email`: Integração com Resend (Inbound/Outbound, Mailboxes, SMTP)
- `web_responsive`: Interface mobile/desktop responsiva
- `remove_odoo_enterprise`: Identidade comunitária sem dependências enterprise
